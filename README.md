# Duka AI Engine

A minimal Python project scaffold for the Duka AI Engine.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m duka_ai_engine
```

## Project layout

- `src/duka_ai_engine/` - package source
- `tests/` - test files
